# svidown Frontend

Next.js 16 frontend for svidown video downloader.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Real-time download progress via WebSocket
- Platform auto-detection (YouTube, Facebook, Instagram, TikTok, Twitter, etc.)
- Quality and format selection
- Download speed limiting
- Dark/Light theme support
- Responsive design with Tailwind CSS
